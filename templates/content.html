How to add SEO meta tags to a Flask app

By {{ seo.author }} · {{ seo.published }}

Every page needs a unique title, description and canonical URL. Flask makes this easy when the values live in one dictionary and one template partial renders them.

1. Describe the page

Create a seo dict in your route and pass it to render_template.

return render_template("home.html", seo={
    "title": "My page",
    "description": "A 120-155 character summary.",
    "path": "/my-page",
})

2. Include the partial

Add {% raw %}{% include "_seo.html" %}{% endraw %} inside <head> of your base template.

3. Add structured data

Pass a schema dict and the partial emits it as JSON-LD.

4. Publish a sitemap

Serve /sitemap.xml and /robots.txt so crawlers can find every page.
